# Портал продажи билетов на мероприятия

Учебный проект — **FastAPI + Jinja2**: REST API и готовый веб-интерфейс.
Каталог мероприятий с поиском и фильтрами, бронирование билетов с удержанием
мест на 15 минут, личный кабинет покупателя, админ-панель со статистикой продаж.

## Технологии

| Инструмент | Зачем нужен |
|---|---|
| Python 3.10+ | язык проекта |
| FastAPI | веб-фреймворк: маршруты, зависимости, Swagger UI на `/docs` |
| SQLAlchemy 2.0 | ORM: модели, сессии, транзакции |
| SQLite | база данных (файл `tickets.db`, создаётся автоматически) |
| PyJWT | выпуск и проверка JWT-токенов |
| bcrypt | безопасное хеширование паролей |
| Jinja2 | серверные HTML-шаблоны веб-интерфейса |
| pytest + httpx | автотесты REST API и веб-страниц |
| Docker + docker compose | упаковка и запуск приложения в контейнере |
| uvicorn | ASGI-сервер для запуска |

## Быстрый старт

```bash
# 1. Перейти в папку проекта
cd ticket-portal

# 2. Создать и активировать виртуальное окружение
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Запустить сервер
uvicorn app.main:app --reload
```

Дальше открыть в браузере:

- **Каталог мероприятий (веб-интерфейс)** — <http://127.0.0.1:8000/>
- Swagger UI — <http://127.0.0.1:8000/docs>
- ReDoc — <http://127.0.0.1:8000/redoc>

## Веб-интерфейс (Jinja2)

Поверх того же сервисного слоя работает серверный веб-интерфейс:

| Страница | Путь | Доступ |
|---|---|---|
| Каталог с поиском и фильтрами | `/` | все |
| Карточка события + форма бронирования | `/events/{id}` | бронирование — только после входа |
| Вход / регистрация | `/login`, `/register` | все |
| Личный кабинет: брони, кнопки «Подтвердить»/«Отменить», билеты с QR | `/cabinet` | пользователь |
| Панель статистики | `/admin` | админ |
| Список и формы мероприятий (создать/изменить/удалить) | `/admin/events` | админ |
| Все брони с фильтром по статусу | `/admin/bookings` | админ |

## Модель данных

**users** — пользователи
- `id`, `email` (уникальный), `hashed_password` (bcrypt), `full_name`, `role` (`user`/`admin`), `created_at`

**events** — мероприятия
- `id`, `title`, `description`, `category` (концерт/театр/спорт/фестиваль/выставка/лекция),
  `venue`, `city`, `starts_at` (UTC), `price` (руб.), `capacity` (всего мест),
  `is_published`, `created_at`

**bookings** — брони
- `id`, `user_id`, `event_id`, `quantity`, `price_per_ticket` (цена зафиксирована в момент брони),
  `status`, `created_at`, `expires_at`, `confirmed_at`

**tickets** — билеты (создаются при подтверждении брони)
- `id`, `booking_id`, `event_id`, `user_id`, `code` (уникальный, вида `TKT-4F2A9C1B7E`)


## Эндпоинты

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| POST | `/api/auth/register` | все | Регистрация |
| POST | `/api/auth/token` | все | Вход, выдача JWT (email в поле `username`) |
| GET | `/api/auth/me` | пользователь | Профиль текущего пользователя |
| GET | `/api/events` | все | Каталог: поиск `q`, фильтры `city`, `category`, `date_from`, `date_to`, `available_only`, пагинация |
| GET | `/api/events/categories` | все | Список категорий |
| GET | `/api/events/cities` | все | Города с мероприятиями |
| GET | `/api/events/{id}` | все | Карточка события + свободные места |
| POST | `/api/bookings` | пользователь | Забронировать билеты (удержание 15 минут) |
| GET | `/api/bookings` | пользователь | Мои брони |
| GET | `/api/bookings/{id}` | владелец / админ | Бронь по id |
| POST | `/api/bookings/{id}/confirm` | владелец | Подтвердить бронь — выдаются билеты |
| POST | `/api/bookings/{id}/cancel` | владелец | Отменить бронь |
| GET | `/api/tickets` | пользователь | Мои билеты |
| POST | `/api/admin/events` | админ | Создать мероприятие |
| GET | `/api/admin/events` | админ | Все события, включая скрытые и прошедшие |
| PATCH | `/api/admin/events/{id}` | админ | Изменить мероприятие |
| DELETE | `/api/admin/events/{id}` | админ | Удалить (нельзя при активных бронях) |
| GET | `/api/admin/bookings` | админ | Все брони, фильтр `?status=` |
| GET | `/api/admin/stats` | админ | Статистика: пользователи, брони, выручка, топ событий |
